# 롬아카이브 직원 교육자료 - GitHub + Render 무료 배포

## GitHub (웹에서 1회)
1. https://github.com/new 에서 새 저장소 `loamarchive-staff-training`를 만듭니다. Public 선택, Add README 체크.
2. 생성된 저장소의 Add file > Upload files를 누릅니다.
3. 이 ZIP의 `index.html`, `robots.txt`, `render.yaml` 세 파일을 압축 해제 후 저장소 루트에 업로드하고 Commit changes를 누릅니다.

## Render
1. https://dashboard.render.com/static/new 에서 저장소 `loamarchive-staff-training`를 선택합니다.
2. Branch `main`, Build command `echo ready`, Publish directory `.` 로 설정합니다.
3. 정적 사이트로 배포합니다. Render에서 발급한 onrender.com URL을 아이폰 Safari에서 엽니다.

주의: 제품 사진은 공식몰 외부 서버를 참조합니다. 인터넷 연결, 이미지 URL 및 외부 서버의 접근 제한에 따라 일부 이미지가 안 보일 수 있습니다. 이 사이트는 공개 URL입니다.
